# CineSeat – Movie Ticket Booking System

CineSeat is a simple movie ticket booking website developed as a Full Stack Web Development case study.

The website allows users to select a movie show time, choose seats, and calculate the total ticket price using JavaScript.

## Features

- Movie information display
- Show time selection
- Interactive seat selection
- Seat deselection
- Selected seat count
- Automatic total price calculation
- Booking confirmation
- Simple and responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
